🎬 Playlist MV Player

Amazon Music のプレイリストを YouTube のミュージックビデオで順番に再生
プレイリストを読み込んで「MVを検索して再生」を押してください
—

1. プレイリストを取得

Amazon Music Web 版（music.amazon.co.jp）でプレイリストを開き、曲一覧を選択してコピー → そのまま貼り付けでも解析を試みます。

Spotify のプレイリストは、エクスポートツール（Exportify など）で書き出した CSV ファイルをそのまま読み込めます。

Spotify にログインして、自分のプレイリスト（または URL を指定したプレイリスト）の曲を取り込みます。初回のみ Spotify Developer Dashboard でアプリを作成し、下の Redirect URI を登録して Client ID を貼り付けてください（API は「Web API」にチェック）。

開発モードのアプリでは、ダッシュボードの「User Management」に登録したアカウントでしかログインできません。自分以外が作ったプレイリストは取得できない場合があります。

Amazon Music Web API はクローズドベータです。開発者登録・承認済みで、Login with Amazon のアクセストークンを持っている場合のみ利用できます。

2. YouTube 設定

Google Cloud Console で YouTube Data API v3 を有効化して API キーを発行してください。検索1回あたり 100 クォータ（無料枠は 1日 10,000 ＝ 約100曲）。検索結果はブラウザにキャッシュされます。
